# Proyecto curso de Inteligencia Artificial
En este proyecto realizado durante un curso de inteligencia artificial tuvo como obtejetivo emplear los electroencefalogramas (EEGs)
de pacientes control y diagnosticados de alzheimer para tratar de identficar un marcador de diagnóstico basado en el 
acoplamiento theta-gamma observado en el EEG muchos casos de demencia.
En este proyecto participaron dos bioquímicos y dos informáticos permitiendo ver lo enriquecedora que es en ciencia la colaboración multidisciplinar entre
especialistas de diferentes áreas
